# Data Readiness Matrix (Phase 4, bundle 2026-11-14T05:20:03+00:00)

Status key: **Ready** = in the real bundle and used in scores · **Partial** = in the bundle with exclusions · **Pending** = code ready, data not acquired · **Unavailable** = no defensible source yet (excluded from scores).

Every score carries a `scoreRange` showing how far missing criteria could move it. See [validation_report.md](validation_report.md) and [terrain_integration.md](terrain_integration.md).

## Negative controls (`pipeline/seed/controls.csv`, `pipeline/data/controls.csv`)

Four humid, vegetated sites (Manaus, Freiburg, Can Tho, Galway) are run through the same POWER, NASADEM and MODIS pipeline for `validate_analogs.py`. They are not part of the app bundle. Can Tho has no NDVI (only 5 of 45 composites usable).
